## 1. 技术结论

Halpha 长期采用 Python 后端、React Web 前端、PostgreSQL 持久存储和 NautilusTrader 量化交易栈。成熟组件承担 HTTP、schema、事务、迁移、前端通用组件、行情、指标、回测、订单模型和场所适配；Halpha 只实现自身产品语义和必要边界。

当前精确版本、锁文件、平台结果和配置由 L4 指向代码与配置来源，不在本契约复制。

## 2. 量化组件边界

NautilusTrader 承担行情回调、时钟、指标、策略运行、订单对象和场所客户端。Halpha 不实现第二行情泵、指标引擎、回测撮合、订单状态机或交易连接作为后备。

量化交易基础核心对稳定性、性能和失败语义要求高，默认复用 NautilusTrader 的公开能力。在项目复杂度可接受范围内，先理解并验证与当前结果有关的组件设计、生命周期和扩展点，再通过受支持扩展或薄适配接入 Halpha；不得以局部定制为由自研替代组件已经承担的基础核心框架。

组件缓存、组合和风险投影不是 Halpha 的计划、资金、事实或动作权威。涉及资金边界和归属的数值进入 Halpha 领域前使用确定精度转换并验证单位。

组件升级需检查公开行情与执行契约、订单身份和查询、实时与离线策略输入、数值和时间边界以及目标主机运行。公开能力不足时停止或明确不支持，不自动切换第二实现。

## 3. 应用和数据组件

Web 后端和前端组件只承担通用传输、校验、事务、迁移、呈现和查询缓存。产品路由调用拥有领域；浏览器缓存、日志、邮件和组件状态都不是业务权威。

计划工作台和本机程序化调用复用同一 HTTP 路由、OpenAPI schema 与领域服务。浏览器不携带调用来源标记，写请求必须来自当前精确回环 Origin 并通过 CSRF；同一所有者主机上的原生 Monitor 请求不携带浏览器 Origin/Referer，以 `X-Halpha-Caller: MONITOR` 明确标记来源，并且只允许进入计划创建、草案变更、AI 审核、一次提交并启动及相应查询范围。提交并启动在服务端内部完成临时预览、运行快照和激活，不向调用方开放为独立阶段。带有 Monitor 标记的浏览器来源请求、未知标记、超出计划范围的写请求和非回环 Host 全部拒绝。该标记用于区分本地传输来源，不是远程、多用户或跨主机身份认证；程序化接口不监听非回环地址，也不因此取得数据库或场所凭据。

数据库、迁移或 schema 不可用时，不得形成依赖它们的业务状态，也不得发起相应交易所变更请求。前端不可用时，用户仍能取得交易场所官方接管入口。

Demo 证据包通过只读 HTTP 投影返回给浏览器下载，后端不选择或写入主机任意路径。Live 只从本机非秘密配置读取所有者明确固定的仓库外绝对 JSON 路径和预期内容摘要；实际路径属于本地隐私，不进入计划、激活、API 响应、日志、Git 或外发诊断，激活只保存内容摘要与业务审计字段。加载器必须有大小上限、严格 UTF-8/schema、拒绝符号链接并对规范模型重新计算摘要；文件缺失、变化、不可读或校验失败时拒绝适用的新增风险，不扫描目录、不回退到相邻文件或另一账户证据。证据包与引用都不包含 API Key、账户秘密或场所签名事实，也不产生外部网络投递。

## 4. 运行 profile

- DEMO：运行产品闭环并连接模拟场所，禁止真实账户交易凭据和真实账户交易动作。
- LIVE_READ_ONLY：只观察而不执行。公开前向观察只使用公开行情和可删除输出，不取得产品写或私有账户能力；私有账户观察可以取得当前交易上下文精确绑定的只读账户凭据和 DAT 事实追加能力，用于形成完整账户快照，但不得装载执行客户端、动作 repository、持久动作能力或任何交易所变更请求能力。两种组合互斥且不能相互降级。
- LIVE_WRITE（真实账户交易）：使用同一产品闭环执行用户已启用计划，仅在当前前置事实满足时取得真实账户交易凭据并发起交易所变更请求。

profile 与场所账户类型是两个正交配置轴：profile 决定运行能力，场所账户类型决定精确的环境、账户、端点、凭据命名空间和隔离资源。DEMO 只允许 Demo 账户类型；LIVE_READ_ONLY 与 LIVE_WRITE 只允许明确命名的真实账户类型。带单员公域合约账户与个人合约账户不得由 API Key 内容、运行时探测或浏览器选择临时推断，也不得共用数据库、任务身份、执行互斥、写门文件或产品凭据引用。

账户类型由受控配置声明，场所查询只验证声明而不替代声明。正常 LIVE_WRITE 在取得写门所绑定的同一 API Key 后，必须用场所当前权威签名查询证明带单上下文确为带单员且目标标的处于带单白名单，或证明个人上下文不是带单员；结果缺失、过期、冲突、请求失败或白名单不包含目标标的时拒绝启动或继续新增风险。该验证使用短期缓存并在最终增险提交边界刷新，不能把一次部署期结果永久当作账户事实。已进入只恢复路径的既有责任不以带单资格仍有效为退出前提，但该例外仍不能新增风险。

环境和账户差异由受控配置选择，只允许落在场所适配参数、端点、凭据引用和隔离资源，不得散落为第二业务实现。新增账户类型必须显式增加完整上下文及其反例验证，不能通过复制策略、资金、执行或复盘逻辑形成分叉。存储和运行实例的当前隔离方式由 SYS 详细设计与 L4 共同记录。

环境部署不得以任务已经注册或秘密已经投影代替身份隔离。部署工具必须先把配置声明的逻辑运行身份解析为实际操作系统身份，再授予文件能力、投影秘密或注册任务；身份缺失或不一致时拒绝继续，不得自动改写配置、放宽权限或报告成功。部署资格检查必须以实际任务身份证明 SYS 定义的跨环境、跨角色和固定产品输入写入均被拒绝；Git 只记录逻辑配置形状、检查实现与非私密结论，实际身份、路径和检查证据保留在仓库外。

## 5. 产品构建身份

一个产品构建身份识别实际运行所需的源码、锁定依赖、迁移、前端制品和非秘密配置。研究、普通文档和未进入产品运行的工具不改变产品构建身份。

正常真实账户写能力要求当前 App、Executor 和真实账户交易开关使用同一个产品构建身份，并要求当前数据库安全约束有效；成功提交并启动时保存的运行快照记录当前构建身份。运行快照中的构建身份是确认来源，不是单独的语义兼容版本。较早运行快照可以由当前构建继续读取，但必须先由当前类型化消费者验证其决策依据、订单计划、允许动作和有效期仍受支持；策略计划还必须保持相同策略版本、实现摘要、参数 schema、动作目录和规范参数。任何一项无法验证时只拒绝新的激活和新增风险，仍保留查看、复盘和沿用参数新建入口；不得静默迁移、重写快照内容或仅凭构建号推断兼容。

完整写门绑定当前环境、账户、凭据指纹和产品构建，而不是预授权未发生的订单。完整写入 Executor 可以在数据库当前没有激活时启动并保持空闲；空集合不产生交易权限。普通计划仍在写门关闭时完成显式提交并启动，再由所有者按既有流程打开写门。唯一快速新增入口是服务器严格构造的人工判向剥头皮周期：只在完整写门已经有效打开、Executor 就绪、当前数据库安全索引有效时创建精确激活，创建本身不形成交易所请求；持续 Executor 发现它时及每个最终动作提交时都重新验证当前写门、环境、账户、构建、激活范围和适用的带单 symbol 白名单。任一验证失败不接管或不提交动作，不能把该例外用于普通草案、Monitor 或任意订单输入。

已经运行或退出中的激活保留其运行快照创建时的构建身份作为来源事实，不因后来产品构建变化而改写：当前构建只有在迁移保留全部记录、能够精确验证其运行快照版本、能够读取原动作身份，并且当前开关、事实、CAP 与最终提交检查全部成立时，才继续原计划尚未完成的入场、保护和退出意图。任何一步不成立时拒绝新增风险，不能重新编译或把旧计划身份改成当前构建。产品构建身份只用于追溯和运行输入一致性，不形成第二兼容目录、发布资格或长期观察流程。当前值和生成方式由代码与 L4 记录。

唯一例外是当前交易开关已经关闭、过期或仍绑定旧产品构建时恢复既有、由 Halpha 拥有且处于运行或退出中的真实账户激活。只有在受保护开关完整且权限可信、环境与账户一致、当前 API key 指纹与开关绑定一致、数据库能够证明目标激活，并且最终提交边界证明每个动作可归属且不增加风险时，才允许只恢复撤单、保护、减仓和退出；不得提交入场或其他增险动作，也不得创建新的真实账户激活。该例外只放宽本段明确列出的当前开关有效性和构建绑定，不放宽凭据、权限、快照可读性、归属、方向、数量、只减仓、外部活动冲突或其他最终提交安全约束。

该恢复例外不把已关闭或已过期的开关重新打开，恢复完整条件前不能取得正常真实账户写能力。开关缺失、损坏、访问控制不可信，或者无法证明凭据、环境、账户和唯一激活时，不发起交易所变更请求，由用户通过场所官方入口接管或先重建为关闭状态的可信开关。

## 6. 秘密、备份与故障

秘密使用操作系统或等价外部秘密存储，不进入仓库、业务数据库、前端、日志或构建记录。每个真实账户类型使用独立、不可回退的秘密命名空间；缺少当前上下文的 API Key 时不得读取另一真实账户或 Demo 的 Key。正常真实账户写入只有在产品构建、数据库、唯一执行者、当前计划、资金检查和账户事实都满足后，才读取并使用当前精确账户的真实账户交易秘密；上一节的只恢复例外仅可为核对当前 API key 指纹和处理该唯一激活读取所需秘密，不能借此恢复增险能力。

实际主机绝对路径、非回环 IP、配置或业务内容中的个人邮箱、用户名、主机名、Windows SID、MAC 地址、代理、环境变量实值、完整异常栈和已启用的本机配置属于本地隐私，不进入 Git 文件、构建制品、浏览器输出或可外发诊断。Git author/committer 邮箱是所有者选择的提交身份，可以进入提交元数据，不由本地隐私门禁改写或阻断。仓库只保存使用合成身份、通用示例路径且关闭外部投递的配置形状；本机值通过仓库外配置、环境变量或外部秘密存储注入。L4 只记录变量名、非秘密引用和验证结论，不复制本机取值。提交与推送前必须使用仓库内隐私门禁检查当前内容、提交消息和新增文件历史；门禁只报告类别与文件位置，不回显命中内容，不得以跳过 hook 的方式发布。

所有者在使用产品时形成的非产品事实、材料及其派生制品同样遵守仓库发布边界，不得进入 Git 跟踪内容。仓库中的忽略分组、路径名、样例名、代码注释和门禁类别必须使用中性语义，不得声明某一具体位置包含或曾包含何种私密内容；本地门禁可以指出待处理文件，但不得回显命中内容或按其私密含义给文件贴标签。测试和示例只能使用与所有者事实无关的合成值。Git 中的 L4 只记录产品契约、配置形状和失败关闭授权结论，不记录仓库外的当前事实。

外部网络请求只允许发送当前产品契约与目标协议确实需要的最小字段，到成熟场所适配器、官方接口或用户明确启用的投递目标。默认不接入遥测、行为分析、崩溃收集、外部 Webhook、日志或制品自动上传；不得把本地隐私、完整配置、数据库、账户快照或原始异常作为诊断材料外传。秘密只在目标协议要求时经 TLS 用于预定场所或投递端的鉴权、签名与请求，不进入 URL、普通载荷、日志或错误回显。网络连接在传输层必然向直接目标或代理暴露出口 IP；系统不得宣称消除该事实，也不得在请求载荷、查询参数或诊断字段中主动附加本机、内网或出口 IP。新增外部目标、上传或遥测能力必须取得用户对该具体外部效果的明确授权，并先证明发送字段不含本地隐私。

用户对普通新增风险草案明确提交 AI 审核时，Codex CLI 是该次操作唯一获准的外部推理目标。App 先把计划安全字段、服务端订单预览、公开行情窗口和汇总纪律写入一次性有界本地输入，在隔离的只读、无用户配置、仅继承启动只读命令所需核心系统变量且按白名单排除凭据与代理、短时会话中以固定提示词和固定输出 schema 调用；不得发送账户引用、环境内部身份、凭据、原始账户快照、数据库内容、本机路径、代理或其他本地隐私，也不得允许 CLI 枚举或读取审核目录外文件。输入、结构化事件输出、内部诊断和运行时间分别设限，一次性文件在终态后删除；推理、工具调用、标准错误和任意诊断不进入浏览器或业务记录。CLI 缺失、超时、退出失败、输出超限或 schema 不符时审核失败关闭，不回退到另一模型或人工伪造批准；审核自身不装载交易凭据、不打开写门、不创建激活，也不直接形成交易所请求。

数据库变更串行迁移；通常在不可逆变化前取得可用备份并完成还原检查。clean-slate 是所有者对明确命名目标的一次性、不可逆退役与重建决定，不是迁移、恢复或回退。只有所有者明确命名目标环境和数据库，明确接受无备份的数据丢失，并放弃目标中全部既有计划、激活、动作、保护、核对、复盘和接管历史，且已经停止目标运行者并关闭目标的场所写能力时，才允许执行。

被放弃的本地历史可以包含已知非终态记录；clean-slate 不要求也不允许为了重建而把这些生命周期伪造成完成、关闭或移交。退役只表示这些记录不再作为 Halpha 当前事实，不证明它们在退役前已经闭合。重建后不得恢复、回放、转换、补发这些记录，也不得从旧数据库、旧备份、日志或其他历史材料推断当前产品事实。未保留备份时，这些数据永久丢失是该决定的明确后果。

本地历史退役不能放弃场所责任。执行清空前，必须以目标环境绑定账户的当前权威只读场所事实证明没有持仓、开放普通订单、开放条件或算法订单，以及未知外部责任；任一结果非零、缺失、过期、冲突或未知时不得执行 clean-slate，而应先按计划、执行与用户接管契约处理。未被明确命名的环境不得触碰。空目标按唯一受支持的当前迁移路径建立，不得把未实际建立的 schema 冒充为当前。备份、恢复、重建或资格检查失败时，该环境保持拒绝真实账户交易动作。

至少验证当前 App、Executor 与开关构建身份不一致、数据库安全约束不可用、API Key 对应的带单状态与声明不一致或带单标的不在当前白名单时，新的真实账户激活和新增风险被拒绝；较早构建固定但语义兼容的计划可以由一致的当前运行实例激活，冻结策略实现或订单计划不受当前消费者支持时拒绝。当前开关重新绑定新构建后，旧构建中已经激活的计划仍按冻结快照和原动作身份继续，且不会重编译、改价、改量或重复提交。只恢复路径仅在受保护开关、当前 API key 指纹、环境、账户和既有激活都可证明时接受不增险动作。开关缺失、损坏、访问控制不可信或目标激活无法证明必须拒绝；关闭或过期开关不会被恢复路径重新打开。程序化计划入口还须验证其与工作台共用完整 schema 和领域路径、Monitor 来源不能由工作台伪造、浏览器来源不能借 Monitor 标记绕过 CSRF、重复请求保持原结果、冲突内容被拒绝、创建或预览不会隐式激活、普通新增风险不能绕过 AI 审核，以及程序化激活仍不直接形成交易所请求。AI 审核还须验证只使用当前精确草案、安全字段和有界公开行情，任何草案修改使批准失效，拒绝 / 失败 / 未知不能固定或激活，CLI 无法访问审核目录外内容，临时输入会清理且公开输出不泄露本机诊断。

本地证据输入还须验证目录不被扫描、符号链接和超限文件被拒绝、摘要与严格 schema 任一不一致失败关闭、实际路径不出现在浏览器或持久业务记录、带单与个人引用不能互相匹配、配置改变进入产品构建身份但不泄露原值，以及读取与校验不会打开写门、装载交易凭据或产生网络请求。
